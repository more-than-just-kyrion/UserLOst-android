# UserLOst-Assets-Alpine

A repository for holding Alpine Linux specific assets for UserLOst

First You Need To Clone The Repo:    

`git clone `

Then You Neeed To Build Alpine:

`cd UserLOst-Assets-Alpine`
`sudo ./buildArch.sh x86_64 (or any other arch you want)`

the arch can be arm, arm64, x86 or x86_64
